## 🛠️ Compilação

Os programas podem ser compilados utilizando o **GCC**:

```bash
gcc main.c -o main
```

Para executar:

```bash
./main
```

Durante os estudos, também podem ser utilizados warnings para facilitar a identificação de problemas:

```bash
gcc -Wall -Wextra -pedantic main.c -o main
```
